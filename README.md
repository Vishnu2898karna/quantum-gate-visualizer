# Quantum Gate Visualizer

This project demonstrates the behavior of basic quantum gates using a visual representation.
It allows users to input quantum states and
apply various quantum gates to observe the resulting transformations.

## Gates  Included

- Pauli-X (NOT) Gate
- Pauli-Y Gate
- Pauli-Z Gate
- Hadamard Gate

## Technologies

-Python
-Qiskit
-Qiskit Aer
-Matplotlib

## Quantum Concepts Covered

-Qubits
-Statevectors
-Superposition
-Bloch Sphere
-Phase
-Measurement
-Quantum Gates
